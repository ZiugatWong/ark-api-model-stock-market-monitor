<div align="center">
<br>
</div>

为 [game.arkengine.me](https://game.arkengine.me)  Ark 站点里的模型股市提供实时价格监控、历史数据可视化、持仓盈亏计算和通知提醒的全功能 Tampermonkey 面板（原 windhub.cc 站点已迁移至此）。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 [Ark 模型股市监控脚本](https://greasyfork.org/zh-CN/scripts/582321)进入 Greasy Fork 并安装脚本
3. 访问 [game.arkengine.me](https://game.arkengine.me)
4. 点击浏览器工具栏的 Tampermonkey 图标，选择相应面板打开

## 功能面板

所有面板均支持独立显示/隐藏、拖拽移动，标题栏左侧为面板名，右侧为操作按钮。

### 1. 主监控面板
**打开方式：** Tampermonkey 菜单 → "主监控面板"

```
┌────────────────────────────────────────────────────┐
│ Ark 模型股市监控 ver x.x.x      ☀️ 🥶 ⚙  ✖️       │
├────────────────────────────────────────────────────┤
│ 选择监控模型                                         │
│  ┌────────────────────────────────────────┐        │
│  │ [glm-5] [claude-3] ... 点击选择模型...  ▼│        │
│  └────────────────────────────────────────┘        │
│  已监控模型: 支持搜索、全选、清空，可拖拽排序、单独删除 │
│                                                    │
│ 行情数据                                            │
│  [最新价格] [活跃套利榜] [我的持仓]                    │
│                                                    │
│ 市场状态                                            │
│  ● 开市 / ● 休市                                    │
│  买卖手续费: buy% / sell%    持仓时长: N 分钟        │
└────────────────────────────────────────────────────┘
```

**功能：**
- 添加/删除监控模型（模型选择器支持搜索、全选、清空，已监控列表支持拖拽排序与单独删除）
- 手动/自动获取价格数据
- 快速打开其他面板的入口
- 市场状态展示（开闭市、买卖手续费、持仓时长）
- 日间/夜间主题切换（标题栏上的 ☀️ 和 🌙 按钮）

### 2. 最新价格
**打开方式：** Tampermonkey 菜单 → "最新价格面板" 或 主面板按钮"最新价格"

```
┌────────────────────────────────────────────────────┐
│ 最新价格（最近 5 条）                         💡 ✖️  │
├────────────────────────────────────────────────────┤
│ ↻ 最近更新: 2026-06-12 10:30:00                     │
│    可用代币: 1,500   持仓总值: $5,000.00             │
│ ┌────────────────────────────────────────────────┐ │
│ │ 时间          │ glm-5 │ claude-3 │ gpt-4 │ ...  │ │
│ ├────────────────────────────────────────────────┤ │
│ │ 10:30:00     │ 120.5↑│  98.3↓  │ 150.0  │ ...  │ │
│ │ 10:25:00     │ 119.8 │  99.1   │ 150.0  │ ...  │ │
│ │ 10:20:00     │ 118.5 │ 100.2   │ 149.5  │ ...  │ │
│ └────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────┘
```

**功能：**
- 显示最近价格记录（默认 5 条）
- 价格变化三态颜色提示（绿↑ 涨 / 红↓ 跌，价格不变时继承上一颜色）
- 显示可用代币和持仓总值（点击持仓总值打开"我的持仓"）
- 表头 💡 按钮提供使用小提示
- 点击模型名打开分时走势图
- 右键点击模型名设置颜色标识（红/绿/黄/橙/粉/青六种颜色）
- 紫色模型名表示有持仓，名称前 🔒 表示持仓锁定中
- 手动刷新按钮

**打开方式：** 主面板"活跃套利榜"按钮

│ ┌────────────────────────────────────────────────┐ │
│ │ 模型名称     │ 最高  │ 最低  │ 价差  │ 幅度 │      │ │
│ ├────────────────────────────────────────────────┤ │
│ │ glm-5-chat  │ 125.5 │ 98.3  │ 27.2 │+27.67%│   │ │
│ │ claude-3    │ 110.2 │ 88.9  │ 21.3 │+23.96%│   │ │

- 排序字段：每股套利价差 / 每股套利幅度

### 4. 我的持仓
**打开方式：** 在"最新价格"面板中点击持仓总值 或 主面板"我的持仓"按钮

```
┌────────────────────────────────────────────────────┐
│ 我的持仓                                       ✖️   │
├────────────────────────────────────────────────────┤
│ ↻ 最近更新: 2026-06-12 10:30:00                     │
│ ┌────────────────────────────────────────────────┐ │
│ │ 模型 │ 股数 │成本价│ 现价 │含费成本│费后收入│盈亏%│解锁││
│ ├────────────────────────────────────────────────┤ │
│ │ glm-5 │  50 │102.3 │110.0 │ 5229.7 │ 5362.5 │+2%│14:00││
│ │ claude │  30 │ 95.5 │ 92.0 │ 2921.6 │ 2691.0 │-8%│14:00││
│ └────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────┘
```

**功能：**
- 显示当前持仓列表
- 持仓明细：股数、成本价、现价、含费成本、费后收入、实际盈亏、盈亏幅度、解锁时间
- 费率从市场规则（`buyFeePct`/`sellFeePct`）动态获取，非硬编码
- 解锁时间颜色提示（红=未解锁，绿=已解锁）
- 自动刷新

> 注意：新站点不再提供独立的交易历史接口，原"我的交易"面板已移除。单笔买卖记录改由分时图中的交易标记点呈现（买=红点，卖=绿点）。

### 5. 设置（监控设置）
**打开方式：** 主面板标题栏 ⚙ 按钮

```
┌───────────────────────────────────────────────────┐
│ 监控设置                                       ✖️  │
├───────────────────────────────────────────────────┤
│ 定时获取最新价格                                    │
│   ☑️ 启用  [手动获取]                               │
│   匹配分钟尾数: [3,8]  [保存]                       │
│                                                   │
│ 价格突破提醒                                        │
│   [测试已打开的提醒]                                │
│   ☑️ 浏览器弹窗提醒                                 │
│   ☑️ 提示音                                        │
│   ☑️ Telegram提醒   Bot Token/Chat ID             │
│   ☑️ Bark提醒       Bark URL                      │
│                                                   │
│ 添加模型价格突破提醒                                 │
│   模型: [glm-5-chat ▼]                            │
│   向上突破: [120] 向下突破: [100] [添加]             │
│   已设置提醒:                                      │
│   • glm-5-chat: ↑120 / ↓100 [删除]                │
└──────────────────────────────────────────────────┘
```

**功能：**
- 定时自动获取设置（分钟尾数触发器，如 `3,8` 表示每小时 03、08、13、18... 分钟触发）
- 手动获取按钮
- 价格突破通知配置（向上/向下突破价格）
- 通知方式：浏览器弹窗、提示音、Telegram 推送、**Bark 推送（iOS）**
- ⚠️ Telegram / Bark 通知跨域推送第一次会请求脚本的跨域权限（GM_xmlhttpRequest），同意即可
- 测试配置后的通知提醒

### 6. 数据维护
**打开方式：** 主面板标题栏 🥶 按钮

```
┌───────────────────────────────────────────────────┐
│ 数据维护                                        ✖️ │
├───────────────────────────────────────────────────┤
│ 数据清理                                           │
│   全部数据大小: 123 KB [↻]                         │
│   价格数据保留天数: [  7  ]  [保存]                 │
│   注: 设置后不立即清理，待第二天第一次获取数据时       │
│       自动清理超出一段时间的数据                     │
│                                                   │
│ 数据同步                                           │
│   数据服务地址: [ http://localhost:3210 ]           │
│   [价格同步]   （同步最近 7 天的价格数据）            │
└───────────────────────────────────────────────────┘
```

**功能：**
- 显示/重新计算全部存储数据大小
- 设置价格数据保留天数（默认 7 天）
- 自动清理超期旧数据（第二天第一次获取数据时触发）
- 支持从自建远程数据服务同步最近 7 天历史价格数据（变更后点击"价格同步"触发）

## 分时走势图

**打开方式：** 在"最新价格"面板中点击模型名称

**功能：**
- 显示价格走势曲线
- 今日最高/最低价线标记
- 持仓成本线标记（有持仓时）
- 交易标记点（买=红点 / 卖=绿点）
- 价格线标签显示/隐藏切换
- 支持拖拽移动和八向调整大小
- 滚动缩放时间范围
- 数据自动刷新（定时或手动获取后联动更新）

## 特色功能

- **多面板管理**：所有面板支持独立显示/隐藏、拖拽移动、z-index 置顶
- **主题切换**：支持日间/夜间模式（通过 🍀/🌙 切换并持久化）
- **价格提醒**：价格突破设定值时自动通知（弹窗/声音/Telegram/Bark）
- **模型颜色标识**：右键设置模型颜色，便于区分多个监控模型
- **持仓盈亏计算**：含买卖手续费的真实盈亏核算
- **市场状态**：开闭市、买卖手续费、持仓时长即时展示
- **数据缓存**：5 分钟缓存机制（模型列表），减少 API 调用
- **自动清理**：按保留天数自动清理旧价格数据
- **数据同步**：从自建服务批量拉取历史价格
- **旧数据迁移**：首次启动自动从旧版 windhub_stock_data 迁移（含模型名/pk 重建）

## 技术栈

- Tampermonkey UserScript
- Lightweight Charts v4.0.1（图表库）
- Web Audio API（声音通知）
- Telegram Bot API / Bark（推送通知，可选）
- 同源 cookie 鉴权（ptd_session）
